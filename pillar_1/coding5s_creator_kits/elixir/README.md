# 💧 Coding5s Elixir Creator Kits

This directory houses the operational **Creator Kit Excel frameworks** for Elixir development, covering core language paradigms and distributed system architecture.

Each kit leverages the **Coding5s micro-learning methodology** to convert functional programming concepts into structured, hands-on practice modules.

---

### 📂 Available Creator Kits

*   **Coding5s Elixir Fundamentals:** The core curriculum focused on functional patterns, pattern matching, recursion, and Elixir's basic data types.
*   **Coding5s Elixir OTP:** Advanced modules for building fault-tolerant, distributed systems using GenServers, Supervisors, and the OTP design principles.

---

### 🚀 Quick Start
1. Choose the **Creator Kit** (.xlsx) matching your current learning target (Fundamentals or OTP).
2. Follow the standardized workflow defined in the `CURRICULUM_GENERATOR.md` (located in the repository root) to generate and inject your curriculum formulas.
3. Utilize the output to build your local practice environment.

*For methodology documentation and framework updates, please visit the main [Coding5s Framework](https://coding5s.dev) repository.*

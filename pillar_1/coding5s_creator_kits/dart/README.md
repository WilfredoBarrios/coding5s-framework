# 🎯 Coding5s Dart Creator Kits

This directory contains the operational **Creator Kit Excel frameworks** for Dart development, designed to accelerate the mastery of language primitives and standard library workflows.

Each kit integrates the **Coding5s micro-learning methodology** to convert complex Dart documentation into structured, hands-on practice modules.

---

### 📂 Available Creator Kits

*   **Coding5s Dart Fundamentals:** The master curriculum for the language, covering core syntax, sound null safety, collection APIs, and synchronous I/O operations.

---

### 🚀 Quick Start
1. Select the **Coding5s Dart Fundamentals** Creator Kit (.xlsx) to begin your curriculum generation.
2. Follow the standardized workflow defined in the `CURRICULUM_GENERATOR.md` (located in the repository root) to generate and inject your curriculum formulas.
3. Utilize the generated output to build your local practice environment and begin your Stage 1 exercises.

*For methodology documentation and framework updates, please visit the main [Coding5s Framework](https://coding5s.dev) repository.*

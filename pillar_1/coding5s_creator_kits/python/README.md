# 🐍 Coding5s Python Creator Kits

This directory contains the operational **Creator Kit Excel frameworks** for Python development, specialized across core scripting and data processing domains. 

Each kit utilizes the **Coding5s micro-learning methodology** to transform technical documentation into structured, executable practice modules.

---

### 📂 Available Creator Kits

*   **Coding5s Python Core And Scripting:** The foundational syllabus covering Python syntax, flow control, and core scripting automation.
*   **Coding5s Python HTTPX:** Focused modules for high-performance, asynchronous HTTP requests.
*   **Coding5s Python Numpy:** Structural computational modules for array manipulation and numerical analysis.
*   **Coding5s Python Pandas:** Data science workflows, focusing on DataFrame operations and time-series analysis.
*   **Coding5s Python Requests:** Simplified modules for standard synchronous API consumption and web interactions.

---

### 🚀 Quick Start
1. Select the specific **Creator Kit** (.xlsx) corresponding to your current learning or development objective.
2. Refer to the `CURRICULUM_GENERATOR.md` in the root repository for step-by-step instructions on syllabus generation and master formula injection.
3. Ensure your local environment is configured to run the output generated by the internal stage formulas.

*For methodology documentation and framework updates, please visit the main [Coding5s Framework](https://coding5s.dev) repository.*

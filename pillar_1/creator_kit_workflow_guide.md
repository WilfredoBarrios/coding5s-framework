# 🛠️ Step-by-Step Guide: Creating a New Course with the Coding5s Creator Kit

This guide outlines the precise execution sequence required to initialize, populate, localize, and deploy a new programming language curriculum within the **Coding5s** framework. Following the automation infrastructure updates, manual tasks like copy-pasting via Notepad and manual formula dragging have been entirely replaced by automated batch scripts.

---

### Step 1: Automated Syllabus Generation Workflow
Follow this 3-phase sequence to generate a production-ready curriculum:

1. **Phase 1 (The Blueprint Generator):** Run the Phase 1 prompt using your target skill (e.g., Python, Google Dorking). This creates the raw domain blueprint and topic ledger.
2. **Phase 2 (The Curriculum Auditor):** Pass the raw ledger into the Auditor Prompt. This refines the topics, applies the "Toolbox" syntax rule, removes theoretical fluff, and sanitizes the output for Excel ingestion.
3. **Phase 3 (The Final Tabulator):** Run the Tabulator Prompt (using the output from Phase 2). This formats the data into the master table, calculates line limits, and applies formatting rules.

---

### Step 2: Ingesting the Master Curriculum
1. Copy the final Markdown table generated in Phase 3.
2. Paste it directly into the **`PromptGenerator`** sheet starting at row 9.
3. Ensure the columns align perfectly with the framework headers in the sheet.

---

### Step 3: Translating and Generating Sub-Rules via Variable Translator Prompt
1. Navigate to the **`Variables`** sheet and locate the **Variable Translator Prompt** infrastructure.
2. Copy the Multi-Language Prompt Architect template.
3. Fill out the required input variables:
   * `[SOURCE_LANGUAGE]`: Specify the origin rules language.
   * `[TARGET_LANGUAGE]`: Specify the destination course language and paradigm.
   * `[TARGET_ECOSYSTEM_PREFERENCES]`: Define tools, framework behaviors, testing suites, and casing standards.
4. Execute the prompt in your LLM to generate the mapped Markdown table containing the new target rule components.

---

### Step 4: Mass Rule Updates via Creator Kit Updater (Optional)
If you need to propagate global framework adjustments or rule changes across multiple files or a template base:
1. Populate your updated parameter matrix inside **`creator_kit_Base_File_for_CKs.xlsx`**.
2. Run **`Creator Kit Updater Runner.bat`** (or execute `creator_kit_updater.py`) to mass-update all target Creator Kits instantly via background COM automation without affecting visual styles or conditional formats.

---

### Step 5: Updating Language and Metric Constraints
1. Navigate to the **`PromptGenerator`** sheet.
2. Type the name of your new target programming language in English inside cell **`B6`**.
3. Go to column A (`Max Lines`) and update the values to define the maximum execution line limits for the exercises generated by Stage 1 prompts.
4. **For Project rows:** Enter **`N/A`** across column A, as executable line boundaries apply strictly to Topic lessons.

---

### Step 6: Automated Formula Ingestion via Formula Auto-Injector
Instead of manual copying, Notepad cleaning, and dragging cells manually down to row 200, automate the entire stage population using the built-in injection engine:

1. Open `copy_paster_Prompt_Formulas_for_CK.py` in your text editor and ensure **`ARCHIVO_CREATOR_KIT`** matches the exact filename of the Creator Kit you are editing.
2. Run **`copy_paster_Prompt_Formulas_Runner.bat`** (or execute `copy_paster_Prompt_Formulas_for_CK.py`).
3. **Safety Guard Verification:** The script reads green generator ranges (`FGen_S1` through `FGen_S5`), measures their compiled character length, and verifies they remain well beneath Excel's **8,100-character safety limit**. If an error occurs, it aborts instantly without saving to protect your file.
4. The script automatically injects the compiled formulas across all ranges (`Topics`, `Projects`, `Mentors` up to row 200) natively in background memory.

---

### Step 7: Compiling and Localizing Student Kits
Once your Creator Kit is fully generated and verified:
1. Open `student_kit_creator.py` and set your desired target distribution language in the **`RESULTS_IN_LANGUAGE`** variable (e.g., `"English"`, `"Spanish"`).
2. Run **`Student Kit Creator Runner.bat`**.

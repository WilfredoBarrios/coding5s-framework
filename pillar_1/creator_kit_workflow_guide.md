# 🛠️ Step-by-Step Guide: Creating a New Course with the Coding5s Creator Kit

This guide outlines the precise execution sequence required to initialize, populate, and deploy a new programming language curriculum within the Creator Kit framework. Follow these steps sequentially to ensure complete architectural integrity.

---

### Step 1: Automated Syllabus Generation Workflow
Follow this 3-phase sequence to generate a production-ready curriculum:

1. **Phase 1 (The Blueprint Generator):** Run the Phase 1 prompt using your target skill (e.g., Python, Google Dorking). This creates the raw domain blueprint and topic ledger.
2. **Phase 2 (The Curriculum Auditor):** Pass the raw ledger into the Auditor Prompt. This refines the topics, applies the "Toolbox" syntax rule, removes theoretical fluff, and sanitizes the output for Excel ingestion.
3. **Phase 3 (The Final Tabulator):** Run the Tabulator Prompt (using the output from Phase 2). This formats the data into the 8-column master table, calculates `Max Lines`, injects `PROJECT` rows, and applies the Markdown pipe-escape rule.

### Step 2: Ingesting the Master Curriculum
1. Copy the final Markdown table generated in Phase 3.
2. Paste it directly into the **`PromptGenerator`** sheet starting at row 9.
3. Ensure the columns align perfectly with the `#`, `Level`, `Type`, `Topic for AI`, and `Topic Name` headers in the sheet.

### Step 3: Translating and Generating Sub-Rules via Variable Translator Prompt
1. Navigate to the **`Variables`** sheet and locate the **Variable Translator Prompt** infrastructure.
2. Copy the Multi-Language Prompt Architect template.
3. Fill out the required input variables:
   * `[SOURCE_LANGUAGE]`: Specify the origin rules language (e.g., *Python Core and Scripting*).
   * `[TARGET_LANGUAGE]`: Specify the destination course language and paradigm (e.g., *Dart Object Oriented and Advanced Patterns* or *Elixir OTP*).
   * `[TARGET_ECOSYSTEM_PREFERENCES]`: Define tools, framework behaviors, testing suites, and casing standards.
4. Append the complete raw variable table rows under the `[INPUT_TABLE]` block as your source of truth.
5. Execute the prompt in your LLM to generate the mapped Markdown table containing the new target rule component column.

### Step 4: Sanitizing and Ingesting the New Language Variables
1. Copy the complete Markdown table generated by the LLM.
2. Paste this table temporarily into a separate, clean spreadsheet or text editor.
3. Delete the original source language column to isolate exclusively the newly translated rules.
4. Copy the remaining values of this sanitized table and paste them directly as values (**Paste Values Only**) into their corresponding rows inside the **`Variables`** sheet of the Creator Kit, ensuring no formula breaks or row shifts occur.

### Step 5: Updating Language and Metric Constraints
1. Navigate to the **`PromptGenerator`** sheet.
2. Type the name of your new target programming language in English inside cell **`B6`**.
3. Go to column A (`Max Lines`) and update the values to define the maximum execution line limits for the exercises generated by the Stage 1 prompts.
4. **For Project rows:** Enter **`N/A`** across column A, as executable line boundaries apply strictly to Topic lessons.

### Step 6: Compiling and Injecting Master Formulas
1. Navigate to the formula generator tracking sheets starting with **`FGen_S1`** and moving sequentially through the stages.
2. Locate the highlighted green tracking ranges designated for **Topics**, **Projects**, and **Mentors**.
3. Select and copy the exact green cell range for your target track.
4. Open **Notepad** (or any plain text editor) and paste the copied formula range.
5. **Character Boundary Check:** Review the pasted payload inside Notepad to confirm it does not exceed the native **8,190-character limit** of Microsoft Excel.
6. Select the entire formula string inside Notepad, copy it, and return to your active spreadsheet grid.
7. Paste the sanitized formula payload directly into the first active lesson cell of its respective stage column:
   * **For Topics:** Paste into the first active row of the `Stage Prompt` column.
   * **For Projects:** Paste into the first active row of the `Stage Project` column.
   * **For Mentors:** Paste into the first active row of the `Mentor Prompt` column.
8. Drag or double-click the fill handle of the newly updated formula cell vertically down through all subsequent rows of that stage matrix.
9. Repeat this process for every Stage tab. Once all stages are populated, the new course is fully generated and ready to use.

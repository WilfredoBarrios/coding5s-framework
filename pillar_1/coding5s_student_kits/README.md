# 🎓 Coding5s Student Kits

This directory contains the **Finalized Courseware** ready for student consumption.

* **Purpose:** These are the static, compiled artifacts generated from the Creator Kits.
* **Content:** Final Markdown lab manuals, exercise instructions, and project briefs exported in a clean, student-friendly format.
* **Usage:** These files are strictly for distribution. Please do not perform structural edits here; all curriculum changes must be executed within the `coding5s_creator_kits` engine.

---
*If you need to update the curriculum content, please return to the [creator_kit_workflow_guide.md](../creator_kit_workflow_guide.md) to regenerate the kits.*

\# 🎯 Coding5s Framework: The Post-AI Educational Standard



\*\*Coding5s\*\* is an open-source pedagogical framework designed to eradicate "Tutorial Hell" through \*\*Controlled Cognitive Friction\*\*. In the Post-AI era, software engineering is shifting from syntax writing to system auditing. This framework provides creators, universities, and developers with the tools and prompts required to train resilient, critical-thinking technical professionals.



\---



\## 💡 The Philosophy: Controlled Cognitive Friction



Traditional tutorials encourage passive consumption ("spoon-feeding"). Coding5s reverses this by introducing calculated obstacles at every step of the learning curve, forcing active learning, execution under pressure, and systemic comprehension.



\---



\## 🔄 The 5 Core Stages



1\.  \*\*Stage 1: Practice (Aislar)\*\* - Establish a baseline with structured hands-on synthesis.

2\.  \*\*Stage 2: Debug (Romper)\*\* - Intentionally break syntax and logic to build diagnostic tracking skills.

3\.  \*\*Stage 3: Complete (Completar)\*\* - Omit critical structural components to force deep logic injection.

4\.  \*\*Stage 4: Refactor (Limpiar)\*\* - Optimize chaotic or "spaghetti" code for performance and readability.

5\.  \*\*Stage 5: Extend (Extender)\*\* - Scale requirements to test adaptability and structural defense.



\---



\## 🛠️ The Prompt Engine: Why Excel?



The core engine of the Coding5s framework is built upon advanced, declarative spreadsheet formulas (`.xlsx`). This choice represents a deliberate architectural decision focused on:



\*   \*\*Zero-Dependency Setup:\*\* No runtimes, virtual environments, or package installations required for course creators.

\*   \*\*Visual Prompt Engineering:\*\* Real-time, instant feedback loop for prompt concatenation and formatting.

\*   \*\*Long-Term Stability:\*\* Maximum backward compatibility ensuring the tooling remains functional towards 2030 and beyond.

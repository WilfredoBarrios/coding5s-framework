# 📂 First 10 Lessons: CCNA Core Connectivity Baseline

This directory contains the completed markdown output for the first 10 lessons of the CCNA Packet Tracer curriculum, generated using the **Stateful5s** architecture. 

These lessons establish the foundational network hardening, local/remote access management, and Layer 2 switching infrastructure for the initial enterprise campus topology.

---

## 🗺️ Lesson Index

Below is the sequential breakdown of the compiled Socratic lessons. Click on any module to view the final interactive learning payload:

* **[Lección 01] [01_physical_topology_baseline.md](./01_physical_topology_baseline.md)**
    * *Focus:* Setting up the initial network hardware footprint, physical cabling interfaces, and structural baseline inside Packet Tracer.
* **[Lección 02] [02_configure_hostnames.md](./02_configure_hostnames.md)**
    * *Focus:* Establishing the device identification layer and configuring system hostnames across core routers and distribution switches.
* **[Lección 03] [03_configure_local_access.md](./03_configure_local_access.md)**
    * *Focus:* Deploying local user databases, setting up the `enable secret` hierarchy, and activating global reversible password encryption.
* **[Lección 04] [04_configure_ssh_access.md](./04_configure_ssh_access.md)**
    * *Focus:* Securing VTY lines by generating RSA crypto keys, forcing SSH v2 remote management, and explicitly disabling legacy Telnet access.
* **[Lección 05] [05_basic_device_hardening.md](./05_basic_device_hardening.md)**
    * *Focus:* Applying control-plane protection via legal MOTD login banners, EXEC session timeouts, and basic console line optimization.
* **[Lección 06] [06_hq_vlan_assignment.md](./06_hq_vlan_assignment.md)**
    * *Focus:* Creating logical broadcast domains, naming subnets, and binding specific access ports on the Headquarter Switch (HQ-S1).
* **[Lección 07] [07_branch_vlan_assignment.md](./07_branch_vlan_assignment.md)**
    * *Focus:* Mirroring broadcast domain logic and configuring specific local access port security mappings on the Branch Switch (Branch-S2).
* **[Lección 08] [08_configure_trunk_links.md](./08_configure_trunk_links.md)**
    * *Focus:* Setting up 802.1Q encapsulation links between switches to carry multi-VLAN traffic across switching segments.
* **[Lección 09] [09_spanning_tree_config.md](./09_spanning_tree_config.md)**
    * *Focus:* Optimizing the Layer 2 loop-prevention topology via Rapid PVST+ configurations and deterministic Root Bridge placement election.
* **[Lección 10] [10_portfast_bpduguard.md](./10_portfast_bpduguard.md)**
    * *Focus:* Edge port hardening using Spanning Tree features like PortFast for immediate access and BPDU Guard to block unauthorized switches.
